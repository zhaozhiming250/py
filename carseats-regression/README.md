## 结论速览

| 题目 | 核心结论 |
| --- | --- |
| 第 1 题 | 由最小二乘一阶条件 dQ/db0 = 0 推出 SUM(e_i) = 0；dQ/db1 = 0 推出 SUM(x_i * e_i) = 0。等价于矩阵形式 X' * e = 0。含义：回归线过样本均值点 (xbar, ybar)，残差与自变量正交、与拟合值正交。前提是模型含截距项。 |
| 第 2 题 | 加入变量扩大了参数空间，RSS 单调不增，而 TSS 固定，故 R² 永不下降。但残差自由度由 n-p-1 减为 n-p-2，惩罚因子 (n-1)/(n-p-1) 变大；噪声变量带来的 RSS 期望下降恰好约一个 sigma²，被损失的自由度抵消，故调整 R² 约 68% 的概率下降。精确判据：调整 R² 上升 等价于 abs(t) > 1。 |
| 第 3 题 (1) | 基准组 = **Bad**。三水平按字母序为 Bad / Good / Medium，模型只含 Good 与 Medium 两个哑变量，未单独出现的 Bad 即基准组。 |
| 第 3 题 (2) | 控制价格、收入、广告后，Good 货架门店比 Bad 货架门店平均多卖 **4.8359 千个（约 4836 个单位）**，95% 置信区间 [4.33, 5.35]，p 约等于 5.5e-56，相对提升约 89%。 |
| 第 3 题 (3) | VIF：Price 1.008、Income 1.012、Advertising 1.009、ShelveLoc 哑变量约 1.50（整体项 GVIF^(1/(2*df)) = 1.003）。全部远低于阈值 5，**不存在多重共线性风险**。 |

## 第 3 题模型拟合报告

回归方程（以 Bad 为基准组）：

```
Sales_hat = 10.3916
          - 0.0570 * Price
          + 0.0137 * Income
          + 0.1056 * Advertising
          + 4.8359 * (ShelveLoc == Good)
          + 1.8959 * (ShelveLoc == Medium)
```

| 变量 | 系数 | 标准误 | t | p 值 |
| --- | --- | --- | --- | --- |
| Intercept | 10.3916 | 0.5213 | 19.933 | 1.23e-61 |
| ShelveLoc[Good] | 4.8359 | 0.2597 | 18.624 | 5.52e-56 |
| ShelveLoc[Medium] | 1.8959 | 0.2132 | 8.894 | 2.15e-17 |
| Price | -0.0570 | 0.0037 | -15.480 | 1.46e-42 |
| Income | 0.0137 | 0.0031 | 4.399 | 1.40e-05 |
| Advertising | 0.1056 | 0.0131 | 8.044 | 1.03e-14 |

模型质量：

```
n = 400,  p = 5,  残差自由度 = 394
R^2 = 0.6268,  调整 R^2 = 0.6221
F = 132.36,  p = 4.89e-82
RSE = 1.7361 千个
AIC = 1582.43,  BIC = 1606.38
TSS = 3182.27,  RSS = 1187.58
```

对照：不含 `ShelveLoc` 的模型 R² 仅 0.2938、调整 R² 0.2884、AIC 1833.57。
加入货架位置后 R² 提升约 0.33、AIC 下降约 251，说明货架位置是价格、收入、
广告之外最重要的解释因素。

## 第 1、2 题验证结果

第 1 题数值验证（n = 50）：

```
含截距模型:  SUM(e_i) = 3.9e-13,     SUM(x_i * e_i) = 4.0e-12   （两者均为 0）
无截距模型:  SUM(e_i) = 5.67,        SUM(x_i * e_i) = -3.3e-12  （前者不再为 0）
```

第 2 题蒙特卡洛模拟（n = 200，原有 p = 3，重复 20000 次）：

```
R^2        上升 19998 次 (99.99%)   不变 2 次   下降 0 次     平均 ΔR² = +2.5e-3
调整 R^2   上升  6292 次 (31.5%)                下降 13708 次 (68.5%)
判据「调整 R² 上升 等价于 abs(t) > 1」在 20000 次中始终成立: True
```

理论与模拟完全吻合：R² 从不下降；调整 R² 约 68% 的概率下降，
且临界点精确对应 abs(t) = 1。
